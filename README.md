# Playwright Web Testing Automation

A professional end-to-end web automation testing project built using **Playwright** and **JavaScript**.

This project demonstrates UI automation, Page Object Model (POM), functional testing, negative testing, checkout testing, logout testing, and automated test execution across multiple browsers.

## 🚀 Tech Stack

- JavaScript
- Playwright
- Node.js
- Git & GitHub
- VS Code
